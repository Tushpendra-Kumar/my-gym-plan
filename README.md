# ⚡ Tushu Gym Plan - Athletic Protocol (100% Offline PWA & Android App)

A high-performance workout app designed for **Tushu** as a personal sportsman training companion. Features the **7 - 12 - 15 Reverse Pyramid Scheme**, automatic set tracking, progressive overload weight memory, rest timer with sound, animated biomechanics motion guides, and 100% offline functionality.

---

## 🎯 7 - 12 - 15 Reps Science (Reverse Pyramid)
- **Set 1: Heavy (7 Reps @ ~80% 1RM)** ➔ Builds raw myofibrillar strength & recruits fast-twitch muscle fibers for explosive power.
- **Set 2: Moderate (12 Reps @ ~70% 1RM)** ➔ Maximizes muscular hypertrophy (lean athletic size & definition).
- **Set 3: Burnout/Pump (15 Reps @ ~55-60% 1RM)** ➔ Muscular endurance, vascularity, and deep metabolic conditioning without joint stress.

*Important:* Do 1–2 dynamic light warmup sets before Set 1 to prime the nervous system and prevent injury.

## 📱 How to Run & Install Completely Offline on Phone

### Android (Chrome):
1. Open the website link in Google Chrome.
2. Tap the **3 dots** (menu) in the top-right corner.
3. Tap **"Add to Home screen"** or **"Install app"**.
4. The app will install as an independent mobile app. It will work **100% offline** in the gym without internet or mobile data!

### iPhone / iOS (Safari):
1. Open the website link in Apple Safari.
2. Tap the **Share icon** (square with arrow pointing up).
3. Scroll down and tap **"Add to Home Screen"**.
4. Tap **"Add"**. Now launch it directly from your home screen offline.

## 🚀 How to Deploy on Vercel or Netlify

### Option 1: Vercel (Super Fast)
1. Push this folder to a GitHub repository (`git init && git add . && git commit -m "initial commit"`).
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Select your GitHub repository.
4. Framework Preset: **Other** (Static HTML).
5. Click **Deploy**. Your live offline-ready link will be generated in 10 seconds!

### Option 2: Netlify (Drag & Drop - No GitHub needed)
1. Go to [netlify.com](https://app.netlify.com/drop).
2. Simply drag and drop the `My GYM Plan` folder onto the Netlify drop zone.
3. You will immediately get a live HTTPS URL (e.g., `https://my-gym-plan.netlify.app`).
